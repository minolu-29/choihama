# ちょいハマ

公開URL：https://minolu-29.github.io/choihama/

1タップで遊べるミニゲーム20本を集めた、10代向けのWebゲームセンター。1回30秒〜1分で終わり、ベスト記録は結果画像にしてXやストーリーにシェアできます。

## ゲーム一覧

| # | ゲーム | 内容 | リンク |
|---|---|---|---|
| 01 | ピタ積み | 動くブロックをタップで落として積む | `#stack` |
| 02 | ピタッと10秒 | 10.00秒ぴったりで止める（3秒後に時計が消える） | `#stop10` |
| 03 | 1→25タッチ | 1から25まで順番にタップ | `#touch25` |
| 04 | 反射神経テスト | 緑になった瞬間にタップ、5回の平均 | `#reflex` |
| 05 | もぐらタップ | モグラだけたたく、ボムは-3秒 | `#mole` |
| 06 | いろ・ことば | 文字の「色」を答える（ストループ） | `#stroop` |
| 07 | ○×暗算 | 式が正しいか判定 | `#math` |
| 08 | 記憶パネル | 光ったマスを覚えてタップ | `#memory` |
| 09 | 光の順番 | 光った順番を再現 | `#simon` |
| 10 | ふわっとジャンプ | タップでジャンプして柱をくぐる | `#flap` |
| 11 | よけまくれ | 落ちてくるブロックをよけ続ける | `#dodge` |
| 12 | ぴったりサイズ | 押している間ふくらむ円を同じ大きさで止める | `#circle` |
| 13 | ゾーンでとめろ | 針がゾーンに入った瞬間にタップ | `#zone` |
| 14 | 大きいのはどっち | 大きいほうの数・式をタップ | `#bigger` |
| 15 | 神経衰弱タイムアタック | 8ペアをそろえるタイム | `#pairs` |
| 16 | この色だけ割れ | 指定の色のシャボン玉だけ割る | `#bubble` |
| 17 | 10をつくれ | 足して10になる2つをタップ | `#make10` |
| 18 | 矢印スワイプ | 青は同じ向き、赤は逆向きにスワイプ | `#arrow` |
| 19 | ヘビのごはん | ヘビを動かしてごはんを食べる | `#snake` |
| 20 | ブロック崩し | バーで打ち返してブロックを崩す | `#breakout` |

URLの末尾に `#stack` などを付けると、そのゲームが直接開きます。結果をシェアするとこのリンクが付くので、見た人がすぐ同じゲームに挑戦できます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（HTML・CSS・JSを1ファイルに収録） |
| `og.png` | SNSでリンクを貼ったときのプレビュー画像 |
| `icon.svg` / `icon-*.png` | タブとホーム画面のアイコン |
| `manifest.webmanifest` | スマホの「ホーム画面に追加」用 |
| `.nojekyll` | GitHub Pagesでそのまま公開するための空ファイル |

ベスト記録と音のオン・オフは、その端末のブラウザにだけ保存されます。
